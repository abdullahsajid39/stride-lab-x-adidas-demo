# STRIDE LAB × adidas — Demo Storefront

A premium demo e-commerce website for a fictional sneaker brand presented as a
collaboration with adidas. Built as a single self-contained page — open
`index.html` in any browser and it runs.

> **Demo concept only.** This is not an official adidas store and is not
> affiliated with adidas. Product names and prices are shown for demonstration.

## What's inside

- Brand-first design: Anton condensed uppercase display type + Archivo body,
  black/white theme with an electric volt accent, three-stripes motif,
  scrolling announcement ticker
- Consistent custom SVG icon set (search, wishlist, account, cart with live
  badge, delivery, returns, authenticity)
- Shop grid with 12 real adidas models (Ultraboost Light, Samba OG, Gazelle,
  Superstar, Stan Smith, Forum Low, NMD_R1, Adizero Boston, Predator Elite,
  Handball Spezial, Campus 00s) with real product photos
- Category and gender filters, price sorting, live search, wishlist hearts
- Product quick-view with size picker
- Working cart drawer: add/remove, quantities, subtotal, free-shipping
  progress bar (free over $150)
- Category tiles, "Collab Drop" feature section, perks strip, newsletter
  signup, full footer — fully responsive with a mobile menu

## Run it

Just open `index.html` in a browser — no build step, no server needed.
Or enable **GitHub Pages** (Settings → Pages → deploy from `main` branch)
to host it on the web.

## Tech

Single-file HTML with inline CSS/JavaScript and embedded image assets.
